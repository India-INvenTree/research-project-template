# research-project-template
Template repository for INvenTree research projects


## How to Use
To use this repository for your own research, simply click "Use this template" at the top of this page. 
Set your repository permissions to private. 
You can make it public once the project is completed.


## Data privacy

As a first step, after cloning the repo, create a folder insider data/ called "raw_private". 
This repo is set up to ignore any folder called "private" (check gitignore file). 
All private data obtained after permissions from the data owner should be stored only in a private folder within the repo.
